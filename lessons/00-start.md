# 시작하기 — 로드맵과 학습 방법

> ⏱ 10분 · 읽기 전용

이 코스의 목표는 하나입니다. **모델을 직접 고치고, 직접 만들고, 직접 학습시켜 보는 것.** 머신러닝 기초부터 딥러닝, LLM, VLM까지 이 사이트 하나로 이어집니다.

이론을 다 알고 시작할 필요는 없습니다. 코드를 돌려보고, 숫자를 바꿔보고, 망가뜨려 보면서 배웁니다. 모든 코드는 실제로 실행해 검증한 것이며, 무료 GPU(Google Colab)에서 돌아갑니다.

> 급하다면 최소 경로: 첫 모델 → 과적합과 검증 → 텐서와 자동미분 → 첫 신경망 → 미니 GPT → LLM 파인튜닝 → 미니 VLM

## 모든 레슨을 관통하는 네 줄

1부에서 개념으로, 2부에서 코드로 만나는 아래 네 줄이 마지막 VLM 학습에서도 **그대로** 나옵니다. 모델이 커지고 데이터가 바뀔 뿐입니다.

```
예측 = 모델(입력)            # forward
손실 = 손실함수(예측, 정답)     # 얼마나 틀렸나
손실.backward()              # 각 파라미터가 손실에 미친 영향(기울기) 계산
옵티마이저.step()             # 기울기 반대 방향으로 파라미터를 조금 이동
```

## 실습 환경: Google Colab

GPU가 없어도 됩니다. 각 레슨 위의 **▶ Colab에서 실행하기** 버튼을 누르면 노트북이 열립니다.

1. 버튼을 눌러 Colab을 연다 (구글 계정 필요)
2. 레슨 상단에 "GPU 필요/권장"이라고 적혀 있으면 메뉴 **런타임 → 런타임 유형 변경 → T4 GPU** 선택
3. 셀을 위에서부터 `Shift+Enter`로 하나씩 실행
4. 내 수정본을 남기려면 **파일 → Drive에 사본 저장**

> Colab 무료 GPU는 사용량 제한이 있습니다. 1·2부는 대부분 CPU로 충분하니 GPU는 3·4부를 위해 아껴 두세요. 다 쓴 노트북은 **런타임 → 런타임 연결 해제 및 삭제**로 꺼 주세요.

## 레슨의 구성

모든 레슨은 같은 순서입니다.

1. **목표** — 이 레슨이 끝나면 할 수 있게 되는 것
2. **본문과 코드** — 설명을 읽고, 실행하고, 출력을 확인
3. **핵심 정리** — 기억할 것 다섯 줄
4. **스스로 점검** — 답을 가린 퀴즈. 막히면 그 부분을 다시 읽으라는 신호입니다
5. **직접 고쳐보기** — 코드를 바꿔 보는 실습. **진짜 수업은 여기**입니다

## 공부하는 방법

- 코드를 실행하기 전에 **결과를 먼저 예상**해 보세요. 예상과 다를 때 가장 많이 배웁니다.
- 셀을 실행만 하고 넘어가지 마세요. 숫자 하나라도 바꿔서 다시 돌려 보세요.
- `print(x.shape)`를 습관처럼 찍으세요. 딥러닝 버그의 절반은 shape 문제입니다.
- 본문에서 점선 밑줄이 있는 단어는 마우스를 올리면(모바일은 터치) 뜻이 나옵니다. 전체 목록은 [📖 용어 사전](#glossary)에 있습니다.
- 막히면 에러 메시지의 **마지막 줄**부터 읽으세요.
- 레슨을 끝내면 맨 아래 **완료로 표시** 버튼을 누르세요. 왼쪽에서 진도를 확인하고 **이어서 학습하기**로 돌아올 수 있습니다(진도는 이 브라우저에 저장됩니다).
